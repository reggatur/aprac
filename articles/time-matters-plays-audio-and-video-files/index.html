Time Matters Plays Audio and Video Files

How to set Time Matters to play audio and video files directly.

Open the Default Applications window in Windows 10

  1. Click the Search field or icon next to the Windows Start Button.
  2. Type: extensions and press Enter

Assign Windows Media Player as the default app in Windows 10

For each type of audio and video file, choose Windows Media Player as the default app.

Common audio and video file types are:.avi, .mov, .m4a, .mp3, .mp4, .wav, .wma

  1. Scroll down to an extension, such as .m4a, and click on Groove Music.
  2. In the pop-up window, click on Windows Media Player.

Repeat these steps for each file extension.

Now, when you save an email with an audio or video attachment or save one of these files as a Time Matters Document record, you will be able to play the file directly from Time Matters by opening the file from a Document record or list.
