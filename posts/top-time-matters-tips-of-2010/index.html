Simple Document Saving

(Updated 6/11/2011)

If your office has not set up Time Matters Document Management, you can still use the handy TM Save button in MS Word, WordPerfect and Acrobat.

To set up simple document saving, disable AutoNaming:

  1. Main Menu | File | Setup | General | Program Level | Forms | Documents
  2. Click: Set Form Options
  3. Uncheck: AutoName checked by default

To use simple document saving:

  1. Create or open a document in Word, WordPerfect, Acrobat or Excel
  2. Press the TM Save button (under Add-Ins in Word)
  3. Fill in: Description, Matter
  4. Press the Lookup button at the right of File Name
  5. Navigate to the right folder.
  6. Type in the Filename, including .doc, .pdf or .wpd
  7. Press: Open
  8. Save and Close the Document record

You can use the above steps for each document you want to save, but there is an easier way. After you have followed the above steps once , Time Matters remembers the Folder for that Matter. You can then pick that Folder from the File Name drop-down list.

To use simple document saving after the first time :

  1. Create or open a document in Word, WordPerfect, Acrobat or Excel
  2. Press the TM Save button (under Add-Ins in Word)
  3. In Description, enter the Document Name and copy it with Ctrl-C
  4. Select the Matter (start typing the name and QuickPik will assist you).
  5. In File Name, type or paste (Ctrl-V) the Document Name
    The next 2 steps are magic! They enter the folder and file extension if followed carefully.
  6. Press: Down, Down until the correct folder is highlighted
  7. Press: Right Arrow, Tab
  8. Press Save & Close
