Word - Change the Return Address for Envelopes

Date: Feb. 15, 2026    Categories: MS Office

Microsoft Word Desktop can create an envelope with a return address from a letter you create. It will use the return address you enter in the MS Word Options.

The PDF guide, Word - Change the Return Address for Envelopes, illustrates how to enter your return address into the MS Word Options.
