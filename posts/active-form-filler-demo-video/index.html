Active Form Filler Demo Video

Date: Feb. 2, 2021    Categories: document management

Watch an online video of Active Form Filler. Using PDF software and this utility, you can fill any form documents containing fields.

Adobe Acrobat forms and other PDF form work well with Active Form Filler.

Active Form Filler Video Demo (MP4)

You can use Active Form Filler to fill forms without Time Matters software. You create a small text file containing the data you want to insert into a form.

Time Matters has a feature, the Formattable Clipboard, that can create the small text file automatically from Contact and Matter records. Other software that can create Mail Merge files can also be used with Active Form Filler.
